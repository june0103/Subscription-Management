# 구독체크 Google Play 이미지 (1.1.0)

Play Console → 스토어 등록정보 → 기본 스토어 등록정보 → 그래픽에 올리는 파일.

- `play-icon-512.png`: 512 × 512, 32비트 PNG. 모서리를 깎지 않은 정사각형(둥근 모서리와 그림자는 Play가 처리).
- `feature-graphic-1024x500.png`: 1024 × 500, RGB PNG.
- `phone-*.png`: 1080 × 1920, RGB PNG 6장. 01→06 순서로 등록.

01(홈)과 06(설정)은 1.1.0 빌드에서 다시 캡처했다(요약 카드 축소·달러 표시, 버전 1.1.0). 02~05는 같은 예시 데이터로
찍은 이전 캡처를 그대로 쓴다. 상태 표시줄은 6장 모두 같은 모양이 되도록 원래 캡처의 것을 쓴다.
화면이 바뀌면 같은 예시 데이터로 해당 화면을 다시 캡처한다.

## 대체 텍스트

- 아이콘: 반투명 달력 위에 코럴색 체크가 있는 구독체크 로고
- 대표 그래픽: 설치된 앱에서 구독 후보를 자동으로 찾는 기능을 강조한 문구와 서비스 검색·추천 목록 카드
- 01-home: 월 예상 지출과 다가오는 구독 결제를 확인하는 홈 화면
- 02-calendar: 구독 결제일과 선택한 날짜의 결제 정보를 보여주는 달력 화면
- 03-monthly-list: 서비스별 금액과 다음 결제일까지 보여주는 월간 구독 목록
- 04-add-subscription: 서비스 이름, 금액, 결제일과 알림 시점을 입력하는 등록 화면
- 05-find-services: 설치된 앱과 추천 구독 서비스를 찾아 선택하는 화면
- 06-reminders: 결제 알림과 알림 시각을 설정하는 화면
