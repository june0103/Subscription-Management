# 구독체크 개인정보처리방침

시행일: 2026년 10월 2일

안개(이하 "운영자")는 구독체크 앱(이하 "앱")을 이용하는 분의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 지킵니다. 이 방침은 앱이 어떤 정보를 왜 처리하는지, 어디에 얼마나 보관하는지, 이용자가 어떻게 거부하거나 요청할 수 있는지를 알려 드립니다.

앱은 회원가입이나 로그인 기능이 없고, 이름·전화번호·이메일처럼 이용자를 직접 알아볼 수 있는 정보를 받지 않습니다.

## 1. 기기 안에만 저장되는 정보

아래 정보는 이용자의 기기 안에만 저장되며, 운영자나 다른 곳으로 전송되지 않습니다.

### 1-1. 이용자가 직접 입력하는 구독 정보
- 서비스명, 결제 금액, 통화
- 결제 주기, 결제일, 알림 시점
- 카테고리, 결제수단 종류(카드, 카카오페이 등. 카드 번호 같은 결제 정보는 받지 않습니다)
- 메모

이 정보는 구독 일정 표시, 이번 달 예상 지출 계산, 결제 알림을 위해 사용됩니다.

### 1-2. 설치된 앱 정보 (자동 찾기·자동완성)
구독 서비스를 쉽게 등록할 수 있도록, 앱은 기기에 설치된 일부 앱의 이름, 패키지 이름, 아이콘을 기기 안에서 확인합니다. 이 정보는 추천 목록을 보여 주는 데만 쓰이며, 기기 밖으로 전송하거나 따로 보관하지 않습니다.

### 1-3. 앱 설정
알림 켜기·끄기, 알림 시각, 사용 통계 보내기 설정은 기기 안의 저장소에 보관됩니다.

## 2. 외부로 전송되는 정보

앱의 개선과 광고 제공을 위해 아래 정보가 Google LLC의 서비스로 전송됩니다.

### 2-1. 앱 사용 통계·오류·성능 정보 (Google Firebase)
앱은 Google Firebase의 Analytics, Crashlytics, Performance Monitoring을 사용합니다.

| 처리하는 정보 | 내용 |
|---|---|
| 기능 사용 기록 | 화면 진입, 구독 추가·수정·삭제, 설치된 앱에서 찾기 사용 여부, 알림 열기 등 |
| 구독 등록 시 기능 사용 정보 | 서비스 구분(앱에 미리 등록된 서비스의 종류만. 직접 입력한 서비스는 '직접 입력'으로만 표시), 카테고리, 결제수단 종류, 결제 주기, 알림 시점, 통화, 메모 작성 여부 |
| 오류 정보 | 앱이 비정상 종료될 때의 오류 위치, 기기 모델, OS 버전 |
| 성능 정보 | 앱 시작 시간, 화면 표시 속도, 일부 기능의 처리 시간 |
| 기기 정보 | Firebase가 발급하는 앱 인스턴스 ID·설치 ID, 광고 ID, 기기 모델, OS 버전, IP 주소로 추정한 대략적인 지역, 언어 설정 |

전송하지 않는 정보: 직접 입력한 서비스명, 결제 금액, 메모 내용, 설치된 앱 목록

- 이용 목적: 기능 이용 현황 분석, 오류 원인 파악과 수정, 앱 성능 개선
- 이용자 선택: 앱의 설정 > 개인정보 > '사용 통계 보내기'를 끄면 위 정보의 전송이 중단되고, 아직 보내지 않은 오류 정보는 삭제됩니다. 꺼도 앱의 모든 기능을 그대로 쓸 수 있습니다.

### 2-2. 광고 (Google AdMob)
앱 홈 화면에는 Google AdMob 광고가 표시됩니다. AdMob SDK는 광고 제공, 광고 성과 측정, 부정 클릭 방지를 위해 다음 정보를 처리합니다.

- 광고 ID, IP 주소(대략적인 지역 추정), 광고·앱 상호작용 정보, 진단 정보

이 처리는 Google의 정책을 따릅니다. 이용자는 기기의 설정 > Google > 광고에서 광고 ID를 재설정하거나 삭제해 맞춤 광고를 제한할 수 있습니다.

- Google 개인정보처리방침: https://policies.google.com/privacy
- Google 파트너 사이트에서 데이터를 사용하는 방식: https://policies.google.com/technologies/partner-sites

## 3. 보유 및 이용 기간

| 정보 | 보관 위치 | 기간 |
|---|---|---|
| 구독 정보, 앱 설정 | 이용자의 기기 | 이용자가 삭제하거나 앱을 삭제할 때까지 |
| 사용 통계 (Firebase Analytics) | Google 서버 | 수집일로부터 14개월 |
| 오류 정보 (Firebase Crashlytics) | Google 서버 | 수집일로부터 90일 |
| 성능 정보 (Firebase Performance Monitoring) | Google 서버 | Google의 보관 정책에 따른 기간 |
| 광고 관련 정보 (Google AdMob) | Google 서버 | Google의 보관 정책에 따른 기간 |

기간이 지난 정보는 Google에 의해 자동으로 삭제됩니다.

## 4. 개인정보 처리의 위탁 및 국외 이전

운영자는 앱 운영을 위해 아래와 같이 개인정보 처리를 위탁하며, 이 과정에서 정보가 국외로 이전됩니다.

| 항목 | 내용 |
|---|---|
| 이전받는 자 (수탁자) | Google LLC (문의: https://support.google.com/policies/contact/general_privacy_form) |
| 이전되는 국가 | 미국 등 Google 데이터센터가 있는 국가 |
| 이전 시기 및 방법 | 앱 사용 중 수시로, 암호화된 네트워크(TLS)를 통해 전송 |
| 이전 항목 | 2-1, 2-2의 정보 |
| 이전 목적 | 앱 사용 통계 분석, 오류·성능 모니터링, 광고 제공 및 성과 측정 |
| 보유 및 이용 기간 | 3항과 같음 |
| 거부 방법 및 효과 | 사용 통계·오류·성능 정보는 설정 > 개인정보 > '사용 통계 보내기'를 끄면 전송되지 않으며, 앱 이용에는 제한이 없습니다. 광고 관련 정보는 광고가 표시되는 앱 특성상 거부할 수 없으나, 기기 설정에서 광고 ID를 삭제할 수 있습니다. |

운영자는 위 경우 외에는 이용자의 정보를 제3자에게 제공하지 않습니다.

## 5. 개인정보의 파기

- 기기 안의 정보: 이용자가 앱에서 구독을 삭제하면 즉시 기기 저장소에서 지워지며, 앱을 삭제하면 기기에 저장된 모든 데이터가 함께 삭제됩니다.
- Google 서버의 정보: 3항의 보관 기간이 지나면 Google에 의해 자동으로 삭제됩니다.

## 6. 이용자의 권리와 행사 방법

- 앱 안에서 언제든지 구독 정보를 확인·수정·삭제할 수 있습니다.
- 설정 > 개인정보 > '사용 통계 보내기'로 사용 통계·오류·성능 정보 전송을 켜고 끌 수 있습니다.
- 알림은 설정에서 켜고 끌 수 있고, 알림 시각도 바꿀 수 있습니다.
- 자동 찾기를 원하지 않으면 사용하지 않고 직접 입력해 등록할 수 있습니다.
- 그 밖에 개인정보와 관련한 열람·정정·삭제·처리정지 요청은 9항의 연락처로 해 주시면 지체 없이 처리하겠습니다. 다만 앱은 이용자를 직접 식별하는 정보를 갖고 있지 않으므로, Google 서버의 통계 정보는 특정 이용자의 것을 찾아 처리하기 어려울 수 있습니다.

## 7. 개인정보의 안전성 확보 조치

- 구독 정보는 운영자의 서버로 보내지 않고 이용자의 기기 안에만 저장합니다.
- 외부로 보내는 정보는 암호화된 통신(TLS)으로 전송합니다.
- 직접 입력한 서비스명, 금액, 메모, 설치된 앱 목록처럼 민감할 수 있는 정보는 분석 정보에서 제외합니다.
- 분석 서비스(Firebase)의 API 키는 이 앱에서만 쓸 수 있도록 제한해 두었습니다.
